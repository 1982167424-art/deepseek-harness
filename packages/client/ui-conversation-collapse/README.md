# @deepseek-ai/dsh-client-ui-conversation-collapse

Auto-collapse AI assistant reasoning/thinking blocks and tool-call blocks after turn completion. User clicks "Expand workflow" to see details.

## Features

- Auto-collapse reasoning blocks after turn completes
- Auto-collapse tool-call and tool-result blocks after turn completes  
- Per-turn "Expand all workflow" / "Collapse" action buttons
- Per-session collapse preference overrides
- Bilingual UI strings (English / Simplified Chinese)
- Settings namespace: `ui-conversation-collapse`
